# Security Policy

## Supported versions

Security fixes are applied to the latest released version on `main`.

## Reporting a vulnerability

Do not open a public issue for a security problem.

Use GitHub's private vulnerability reporting:

https://github.com/brijeshyadav2312/responsive-audit/security/advisories/new

Include the affected version, a minimal reproduction, and the impact. You should receive
an acknowledgement within 7 days and a status update within 14 days.

## Scope

This project launches local browsers and loads the target page you provide. It does not
send page content to a remote service. Auditing authenticated or production pages should
only be done with explicit permission.

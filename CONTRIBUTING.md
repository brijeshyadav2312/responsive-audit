# Contributing

## Setup

Requirements: Node.js 20 or newer, Git, and Playwright Chromium.

```bash
git clone https://github.com/brijeshyadav2312/responsive-audit.git
cd responsive-audit
npm install
npx playwright install chromium
```

## Checks

Run these before opening a pull request:

```bash
npm run validate
npm run validate:skill
npm test
```

For a manual end-to-end check:

```bash
npm run demo
```

The demo page intentionally contains responsive defects, so a non-perfect grade is
expected.

## Pull requests

- Keep the skill folder named `skills/responsive-audit`; validators require the folder
  name to match the `name` in `SKILL.md`.
- Add a regression test for every new measurement rule or false-positive suppression.
- Update the matching file in `skills/responsive-audit/references/` when thresholds,
  checks, devices, or report fields change.
- Do not commit `out/`, `node_modules/`, tarballs, or screenshots generated by local runs.
- Keep documentation and report output ASCII-only.
- Describe the behavior change, the test evidence, and any remaining platform limits in
  the pull request.
